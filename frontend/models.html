Foundation Models

The model stack behind your answers

ENTRAG currently uses Google Gemini for answer generation and embeddings, with a persistent Chroma vector store for document retrieval.

Open your workspace Ask a question

One clear path from question to answer

The model settings are managed by the backend environment, not selected from a list in the user interface.

01 / GENERATION

Google Gemini

The backend uses a Gemini model for responses. The model can be set with GEMINI_MODEL; a default is provided in the backend configuration.

02 / EMBEDDINGS

Gemini embeddings

The gemini-embedding-001 model converts document passages and questions into vectors for semantic retrieval.

03 / RETRIEVAL

Chroma and optional reranking

Chroma persists document vectors. Cohere reranking is optional; the application can use local lexical reranking when it is not configured.

The application requires a Google API key for Gemini. Optional Cohere reranking requires its own key.
