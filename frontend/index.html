Architecture

Built on a RAG Pipeline

ENTRAG follows the Retrieval-Augmented Generation pattern, combining the precision of vector search with the fluency of large language models.

Document Store

MySQL stores account and document metadata used by the application.

Embedding Engine

Gemini embeddings represent document passages for semantic retrieval.

Chroma vector store

Chroma keeps the document vectors used to retrieve relevant passages for each question.

LLM Synthesis

The configured Gemini model uses retrieved context to draft an answer with source references.
